¡Hola Mundo! Mi primer post con Hugo

¡Bienvenido al blog de mi mini sitio web para el módulo de Implantación de Aplicaciones Web (IAW) en 2º de ASIR!

En esta primera entrada inauguramos la sección de artículos estáticos generados con Hugo. A diferencia de los gestores de contenido dinámicos tradicionales que requieren PHP y una base de datos MySQL/MariaDB en cada petición, Hugo compila todo nuestro contenido escrito en Markdown (content/) junto con las plantillas HTML (layouts/) para generar un sitio web estático completo en milisegundos.

Ventajas de un sitio estático en IAW

  1. Velocidad extrema: el servidor web únicamente entrega ficheros HTML y CSS planos ya generados.
  2. Seguridad: al no existir base de datos ni ejecución de código en el servidor al servir las páginas, se reduce drásticamente la superficie de ataque (inyecciones SQL, vulnerabilidades en plugins, etc.).
  3. Control de versiones con Git: todo el sitio (tanto el código fuente como la carpeta de publicación) puede versionarse desde la terminal con git y alojarse gratuitamente en GitHub Pages.
