Sobre mí

¿Quién soy?

Me llamo Manuel Miranda Fernández y curso 2º de Administración de Sistemas Informáticos en Red (ASIR). Me apasiona la infraestructura de red, la administración de sistemas GNU/Linux, el despliegue de servicios web bajo filosofía FLOSS / KISS y la automatización.

Mis áreas de interés en ASIR

  • 🖥️ Administración de servidores GNU/Linux (Debian, Ubuntu Server, Alpine Linux, MAX).
  • 🌐 Implantación de Aplicaciones Web (IAW): servidores Apache/Nginx, sitios estáticos con Hugo, despliegues en GitHub Pages y gestores de contenido.
  • 🖧 Servicios de Red e Internet (SRI): DNS, DHCP, SSH seguro y alta disponibilidad.
  • 🗄️ Bases de datos y SGBD: MariaDB, MySQL y PostgreSQL.
  • 🔧 Automatización y DevOps: Bash scripting, Git desde terminal y contenedores Docker.
